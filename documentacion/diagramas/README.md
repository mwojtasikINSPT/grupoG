# Diagramas UML

Los diagramas fueron contrastados con el modelo, las relaciones JPA, los controladores y la configuración de seguridad del proyecto.

- Los archivos `.uxf` se abren y editan directamente en UMLetino.
- Los archivos `.puml` son una alternativa editable para PlantUML.

## Abrirlos en UMLetino

1. Entrar en <https://www.umletino.com/umletino.html>.
2. Elegir la opción para abrir un diagrama existente.
3. Seleccionar `diagrama-clases.uxf` o `diagrama-casos-uso.uxf`.
4. Revisar la distribución visual y exportar en formato PNG.

## Generar los PNG

1. Abrir <https://www.plantuml.com/plantuml/uml/> o cualquier editor compatible con PlantUML.
2. Copiar el contenido completo del archivo `.puml` correspondiente.
3. Generar el diagrama.
4. Descargarlo en formato PNG conservando estos nombres:
   - `diagrama-clases.png`
   - `diagrama-casos-uso.png`

PlantUML y UMLetino están admitidos por la consigna. El formato propio y editable de UMLetino es `.uxf`.
